# 使用教程

## 登录与启动

访问管理员提供的 HTTPS 地址，用邮箱和密码登录。“我的浏览器”显示当前状态：已休眠、正在启动、运行中、正在保存或需要重启。

- 点击“启动并继续浏览”恢复自己的 Chrome。
- 在网址框输入网页，会启动浏览器并在新标签中打开。
- 另一台设备正在使用时，点击“接管并继续浏览”；旧设备的画面和输入连接会立即关闭。
- 点击“停止”会正常退出 Chrome 并保留数据。所有设备断开 10 分钟后也会自动停止。

云端网站需要独立登录，插件不会复制本机 Cookie。网站自己的登录期限、风控、DRM 或云服务器限制仍然适用。

## 浏览器插件

插件是本机能力桥，不只是打开入口。第一次使用时，在插件弹窗中填写 Cloud Browser 地址，例如 `https://browser.example.com`，并允许插件访问这个域名。插件不会注入其他网站。

安装步骤：

1. 从 GitHub Release 下载 `cloud-browser-extension.zip` 并解压到固定目录。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择刚才的目录，并把 Cloud Browser 固定到工具栏。
4. 打开插件，填写服务完整地址并保存。浏览器只会请求访问该服务域名；更换地址后会移除旧地址的访问权。
5. 登录并接管云端浏览器。画面下方出现“本机能力桥已连接”即表示启用成功。

- 点击远程输入框后，直接使用电脑自己的中文输入法；组合文字确认后会写入远程 Chrome 当前焦点。
- `Ctrl/Cmd+C`、`Ctrl/Cmd+X` 会把远程文字写入本机剪贴板，`Ctrl/Cmd+V` 会把本机文本粘贴到远程焦点；画面工具栏也提供复制和粘贴按钮。
- 远程网站点击文件上传后，插件弹出本地文件选择器；文件先安全上传到当前账号的 `Uploads`，随后自动填入原来的远程文件框。

剪贴板仅在用户执行复制、剪切或粘贴时读写，不进行后台轮询。文件仍受单个 200 MB 和账号存储配额限制。

如果没有出现连接提示，重新打开插件并保存一次服务器地址，确认扩展管理页没有禁用该站点权限。手机及不支持插件的浏览器继续使用页面内的输入和文件面板。

## 声音、输入与全屏

声音默认关闭，点击“声音”后浏览器才建立音频连接。移动端首次播放需要一次用户点击，这是浏览器的自动播放限制。

“输入”面板可以把本地文本写入云端剪贴板，也提供 `Ctrl+L`、`Ctrl+T`、`Ctrl+W`、返回和刷新等常用按键。远程画面侧边菜单可以切换触摸、缩放和剪贴板选项。

## 文件往返

- 从“我的文件”或浏览器页的“文件”面板上传，本地文件进入云端 `Uploads`。
- 网站文件选择器从 `Uploads` 选择文件。
- 网站下载内容进入云端 `Downloads`；下载完成后，再从文件面板保存到本机。
- 单次上传上限 200 MB。未完成的临时下载不会出现在列表中。

## 修改自己的密码

打开“账号设置”，输入当前密码和两遍新密码：

![账号密码设置](images/account-password.png)

保存成功后，当前设备继续登录，其他设备的登录和控制连接会被撤销。新密码至少 12 个字符，建议由密码管理器生成。

## 管理员功能

“管理空间”可以：

- 创建 48 小时有效、仅能使用一次的邀请链接。
- 禁用或重新启用普通账号；禁用会立即注销该用户。
- 停止某个用户的浏览器并保留 Profile。
- 查看运行会话、磁盘和可用内存。

管理员无法查看其他用户的浏览画面、Cookie、剪贴板正文或文件内容。日常日志也不记录密码和完整网址。
