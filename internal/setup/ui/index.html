DATABASE

选择数据库来源

打开向导不会创建数据库。只有确认使用内置 PostgreSQL 后，安装程序才会创建一个项目专用服务。

“本机”指运行 Cloud Browser 的 Linux 服务器。PostgreSQL 必须监听 Docker 网桥可访问的地址，并在 pg_hba.conf 中允许 Docker 网段；仅监听 127.0.0.1 时无法连接。

ACCESS

设置访问地址

域名需提前解析到这台服务器。新服务器推荐让 Cloud Browser 自动管理 HTTPS。

ADMINISTRATOR

创建管理账号

该账号可以邀请用户、查看资源和停止异常会话。

CAPACITY

确认运行规模

每个运行中的 Chrome 默认最多使用 2 GB 内存和 2 个 CPU 核。
